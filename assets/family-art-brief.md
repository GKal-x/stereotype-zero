# Family sprites v1

Generated using the built-in image-generation tool in **generate** mode with reference images, then copied to `assets/family-v1.png`. The PNG is preserved unchanged. `family-atlas.js` records twelve measured alpha bounds, four directions each for Mum, Dad and the younger brother. The runtime uses the existing pixel-grid leg rig and nearest-neighbour rendering.

The supplied parent photograph shows later life; the parents are interpreted at approximately 30–35 as requested. The supplied brother photograph shows adulthood; the opening instead uses a small child without adult facial hair. These are provisional stylised interpretations, not verified period likenesses. Original photographs, social-media handles and screenshot UI are not game assets and are not exported. Grandparents, aunt and uncle have no invented likenesses.

## Final generation prompt

Use case: stylized-concept. Asset: a single production sprite atlas for an original top-down handheld-style Athens RPG. Inputs: image 1 is a reference photograph of the parents, image 2 is a reference photograph of the younger brother as an adult, image 3 is the existing game character style reference. Generate NEW sprites inspired by those people, not photographs. Depict the parents as plausible YOUNGER adults aged 30–35, with youthful faces and dark hair, not their age in the photograph. Depict brother Omiros as a small THREE-YEAR-OLD child inspired by image 2's dark wavy hair and facial shape: NO moustache, NO beard, NO adult proportions. Output EXACTLY TWELVE isolated full-body sprites in THREE ROWS and FOUR COLUMNS. Row 1 young mother: short chestnut-dark brown hair with a fringe, red rectangular glasses, burgundy blouse, dark teal trousers, comfortable cream shoes. Row 2 young father: short dark curly hair, modestly high hairline, youthful face, NO grey hair, no old supervisor look; light blue shirt, dark blue jeans, brown shoes. Row 3 small brother: dark wavy short hair, pale teal T-shirt, navy shorts, red trainers, cheerful and energetic. FOUR COLUMNS in EVERY row, in exact order: front facing down, left profile, right profile, back facing up. Consistent clothes and anatomy in all four views. Orthographic game view; whole figures including both feet; compact appealing original JRPG proportions and similar bold silhouette to image 3. Cleaner simpler clusters than image 3, restrained colours, crisp dark outlines, hard pixel-like edges, no blurry painterly shading, no glossy filter, no glow or shadows. Genuinely transparent alpha everywhere outside each sprite; no floor, no scenery, no checkerboard drawn into image. Equal roomy cells, generous separation, sprites never touching. No text, labels, captions, logos, social app UI or copied photo backgrounds. The only content must be the twelve characters.

## Adaptation limits

Clothing, younger hairlines and glasses in the childhood period are proposed costume choices, not established facts. Source sprite resolution is 1536×1024; sprites are sampled into the existing game scale. Human feedback remains necessary for likeness, clothing and pixel clarity.
